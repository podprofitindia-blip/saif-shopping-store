# HomeNest Picks — Affiliate Website

A responsive, mobile-first affiliate storefront starter.

## Included
- `index.html` — complete website
- `assets/` — the supplied product screenshots used as product imagery
- Six supplied Myntra affiliate links wired to the product CTA buttons
- Search/filter, responsive layout, affiliate disclosure and basic privacy modal

## Deploy
Upload the contents of this folder to GitHub Pages, Netlify, Vercel static hosting, or any standard static web host.

## Before publishing
1. Replace the brand name if desired.
2. Verify each affiliate URL and that the corresponding product still matches the card.
3. Add your own real Privacy Policy and Terms pages if you add analytics, forms, cookies, or other tracking.
4. Add your affiliate program disclosures according to the current program terms.

The supplied affiliate URLs are kept exactly as provided by the site owner.
