SAIF SHOPPING STORE — ADMIN DASHBOARD

Files:
- index.html: public storefront
- admin.html: add/edit/delete product dashboard
- product1.jpg ... product5.jpg: put your existing five product photos here

UPLOAD TO GITHUB:
1. Extract this ZIP on your phone.
2. Upload/replace index.html and admin.html in the root of your GitHub repository.
3. Keep the existing product1.jpg through product5.jpg in the repository root. If you have them in this ZIP, upload those too.
4. Commit changes. Open https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/admin.html

IMPORTANT LIMITATION:
GitHub Pages is static hosting. This dashboard stores edits in the current browser only; it does not write to GitHub or sync across visitors. To publish products to everyone, you must export products JSON and update the site's product data in index.html, then commit the change. This is not a secure multi-user admin system and has no login/database.
